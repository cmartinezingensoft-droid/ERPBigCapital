El ZIP fuente no contiene `node_modules` y el entorno de trabajo actual usa Node 22, mientras el proyecto declara Node 16/17/18. Por ello no se certifican en este entorno:

- `pnpm typecheck` completo del monorepo;
- `pnpm build` completo;
- ejecución real de Playwright/E2E contra una aplicación levantada;
- integración real con AEAT, FACe o una entidad bancaria.

La prueba E2E de Fase 10 está implementada y ha pasado validación sintáctica/estructural, pero debe ejecutarse en el entorno reproducible del proyecto antes del despliegue.

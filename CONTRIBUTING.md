# Contribuir a FaroCapital

Las contribuciones deben mantener la compatibilidad con el monorepo, la interfaz en castellano y las validaciones fiscales españolas incluidas en el proyecto. Antes de entregar cambios, ejecuta las comprobaciones de formato, tipos y pruebas disponibles.

El proyecto se distribuye bajo AGPLv3; conserva el archivo `LICENSE` y documenta las modificaciones relevantes.
